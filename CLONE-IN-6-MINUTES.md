# CLONE-IN-6-MINUTES: Быстрый запуск новой студии

Пошаговая инструкция, как за 6 минут запустить онлайн-запись для любого нового автосервиса или детейлинг-студии через один конфигурационный файл `business.json` и изображения, не меняя ни строчки кода приложения.

---

## ⏱ Таймлайн: 6 минут

### Минута 1: Создание структуры студии
Выполните команду в терминале:
```bash
pnpm tenant:new royal "ROYAL Detailing"
```
Команда создаст изолированную директорию студии:
`tenants/royal/business.json`

---

### Минута 2–3: Заполнение реквизитов студии
Откройте `tenants/royal/business.json` и укажите данные бизнеса:
- **`name`**: Официальное название студии
- **`accent_color`**: Фирменный цвет бренда (например, золотой `#D4AF37` или синий `#4690FF`)
- **`phone` & `address`**: Контакты для клиентов
- **`timezone`**: Часовой пояс (например, `Europe/Moscow`)
- **`cancellation_hours`**: Окно бесплатной отмены (например, 24)
- **`buffer_minutes`**: Время на подготовку бокса между машинами (например, 30 минут)
- **`resources`**: Список боксов/подъёмников:
  ```json
  "resources": [
    { "name": "Бокс 1 (Мойка)", "is_active": true },
    { "name": "Бокс 2 (Оклейка)", "is_active": true }
  ]
  ```
- **`services`**: Услуги, длительность, цены и привязка к боксам:
  ```json
  {
    "name": "Комплексная мойка кузова",
    "category": "Мойка",
    "duration_minutes": 60,
    "price": 2000,
    "resource_names": ["Бокс 1 (Мойка)"]
  }
  ```
- **`hero_image_url`**: Ссылка на фото автомобиля в студии
- **`info_cards`**: 3 ключевых преимущества студии для первого экрана

---

### Минута 4: Валидация конвейера
Запустите проверку корректности конфигурации:
```bash
pnpm tenant:validate royal
```
Конвейер автоматически проверит:
- Корректность slug и формата номеров
- Привязку всех услуг только к реально существующим боксам
- Наличие всех 7 дней недели в рабочем графике
- Валидность HEX-цвета и структуры JSON

---

### Минута 5: Публикация и генерация PWA Manifest
Выполните команду публикации:
```bash
pnpm tenant:publish royal
```
Конвейер:
1. Создаст индивидуальный веб-манифест установки PWA: `public/manifests/royal.webmanifest`
2. Настроит персональную иконку, splash-screen и цвет адресной строки
3. При подключенном Supabase автоматически загрузит услуги, боксы и расписание в базу данных

---

### Минута 6: Верификация и активация Live-режима
Запустите финальную проверку готовности:
```bash
pnpm tenant:verify royal
```
Скрипт проверяет:
- Наличие активных боксов
- Заполненность контактов и расписания
- Готовность PWA-манифеста
- Активирует флаг `"is_live": true`

Готово! Отправьте клиенту и владельцу персональные ссылки:
- 📱 **Ссылка для записи клиентов:** `https://your-domain.com/s/royal/`
- 💼 **Кабинет владельца студии:** `https://your-domain.com/s/royal/owner/`

---

## 🛡 Архитектурная изоляция
- Все записи, оплатные операции и клиенты студии `royal` строго изолированы и никогда не пересекаются с другими студиями (`graphite`, `motorplus`).
- Переиздание настроек студии сохраняет все уже сделанные клиентами записи и загруженные фотографии.
