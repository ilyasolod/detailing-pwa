# PWA для детейлинг-центров (MVP 1.0)

Единое универсальное мобильное веб-приложение (PWA) для независимых детейлинг-центров.

- **Архитектура**: Одно универсальное приложение (один репозиторий, один проект Netlify, один проект Supabase, одна PostgreSQL база данных, одно хранилище).
- **Стек**: React, TypeScript, Vite, Tailwind CSS, Supabase (PostgreSQL + Auth + Storage + RPC).
- **Хостинг**: Netlify Free + Supabase Free.
- **Подключение новой студии**: Без изменения кода и без повторного развёртывания.

---

## 🚀 Основные возможности

### 1. Публичная страница студии (`/c/:slug`)
- **Адаптивный Single-Page**: разработан по принципу Mobile-First.
- **Главный экран (Hero)**: логотип студии, название, описание, статус онлайн-записи и кнопка перехода.
- **Портфолио выполненных работ**: галерея фотографий высокого разрешения (Porsche, Mercedes-Benz, BMW, Audi) с полноэкранным Lightbox-просмотром.
- **Каталог услуг с множественным выбором**: выбор сразу нескольких услуг одновременно.
- **Интерактивный предварительный расчёт**:
  - Сумма минимальных цен выбранных услуг (`от 95 000 ₸`).
  - Суммарная продолжительность (`8 часов`).
  - Обязательное пояснение: *«Указанная стоимость является предварительной. Итоговая цена определяется после осмотра автомобиля»*.
- **Форма записи и автомобиль**:
  - Имя клиента
  - Номер телефона (+7 7XX XXX-XX-XX)
  - Марка автомобиля (Toyota, BMW, Mercedes и т.д.)
  - Модель автомобиля (Camry, X5, E-Class и т.д.)
- **Умный расчёт свободного времени**:
  - Обслуживание 1 автомобиля одновременно (по ТЗ).
  - Учитывает суммарную продолжительность всех выбранных услуг, рабочий график, перерывы, существующие брони и ручные блокировки.
- **Атомарное резервирование на 30 минут**:
  - Серверная RPC-функция с транзакционной блокировкой `pg_advisory_xact_lock` (защита от двойных записей).
  - Сгенерированный номер заявки (например, `DL-001`).
  - Заявка сохраняется в статусе `pending` с таймером на 30 минут (`expires_at`).
- **Переход в WhatsApp владельца**:
  - Кнопка **«Отправить заявку в WhatsApp»** (`https://wa.me/...`).
  - Сообщение строго соответствует формату раздела 8 ТЗ.

### 2. Административная панель студии (`/admin`)
- Защищённый вход по email/паролю (Supabase Auth).
- **Полная изоляция данных**: владелец управляет только своей студией (`company_id`), исключён доступ к другим компаниям через RLS.
- **Календарь**: визуальное расписание, внесение записи вручную (по телефону), ручная блокировка интервалов, закрытие дня.
- **Заявки**: список записей, фильтрация по статусам (ожидают, подтверждены, выполнены, отменены), подтверждение, отмена, перенос на другое время (с валидацией доступности), быстрый контакт с клиентом в WhatsApp.
- **Услуги**: добавление, удаление, изменение цен, длительности и активности услуг.
- **Портфолио**: загрузка фотографий, удаление, упорядочивание.
- **График**: настройка рабочих дней недели, времени открытия/закрытия и обеденных перерывов.
- **Настройки**: контактные данные, WhatsApp, адрес и визуальный пресет (Dark Studio, Clean Automotive, Performance).

## 🎨 Дизайн-система: Automotive Premium

Все компании используют общую дизайн-систему, но имеют индивидуальную визуальную идентичность через настройки `design_settings`:
1. **Dark Studio** (`/c/detail-lab`) — глубокая тёмная эстетика с золотисто-янтарными акцентами (`#E5A93C`).
2. **Clean Automotive** (`/c/auto-studio`) — технологичный чистый стиль со спортивным синим акцентом (`#3B82F6`).
3. **Performance** (`/c/prime-detailing`) — динамичный характер с контрастным красным акцентом (`#EF4444`).

## 🔒 Изоляция данных и безопасность

- **Отсутствие общего каталога**: Главная страница `/` не содержит списка клиентов/конкурентов, а перенаправляет на `/admin` или нейтральное инфо-окно.
- **Строгий Row Level Security**: Таблицы `bookings`, `services`, `companies`, `weekly_schedule`, `blocked_intervals` защищены RLS-политиками.
- **Безопасные RPC**: Функции бронирования работают с `SECURITY DEFINER` и фиксированным `search_path = public`.
- **Автоматическая очистка**: Просроченные резервы (старше 30 минут) автоматически переводятся в `expired` и освобождают слоты.

## 💻 Быстрый запуск локально

```bash
# 1. Установка зависимостей
pnpm install

# 2. Запуск тестов
pnpm test

# 3. Запуск dev-сервера
pnpm dev

# 4. Продакшн-сборка
pnpm build
```

Приложение сразу запускается в браузере:
- Главная страница: `http://localhost:5173/`
- Студия Detail Lab: `http://localhost:5173/c/detail-lab`
- Студия Auto Studio: `http://localhost:5173/c/auto-studio`
- Студия Prime Detailing: `http://localhost:5173/c/prime-detailing`
- Панель владельца: `http://localhost:5173/admin`
  - Логин: `owner@detail-lab.kz`
  - Пароль: `password123`
